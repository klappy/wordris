# 📖 Biblical Word Tetris (Wordris)

A unique Tetris-like word game where letters fall from heaven and you form words from Bible verses! Combine the classic gameplay of Tetris with the spiritual enrichment of God's Word.

![Biblical Word Tetris Demo](https://via.placeholder.com/800x400/667eea/white?text=Biblical+Word+Tetris)

## 🎮 Game Features

### 🧩 Dual Game Modes
- **Tetris Mode**: Found words disappear and letters fall down (classic Tetris style)
- **Word Search Mode**: Found words stay highlighted for visual satisfaction

### 📚 Bible Integration
- **Curated Bible Verses**: Hand-picked verses from different books of the Bible
- **Intelligent Difficulty System**: 7-factor algorithm rates verse difficulty
- **Progressive Levels**: Verses get more challenging as you advance
- **Book-Based Difficulty**: Different Bible books have varying complexity ratings

### 🎯 Gameplay Mechanics
- **Falling Letters**: Letters drop from the top like Tetris pieces
- **Multi-Directional Word Formation**: Find words horizontally, vertically, and diagonally
- **Real-Time Scoring**: Points based on word length and difficulty
- **Level Progression**: Unlock higher levels with better scores
- **Achievement System**: Unlock badges for various milestones

### 🎨 Beautiful Design
- **Modern UI**: Sleek glass-morphism design with biblical themes
- **Responsive**: Works perfectly on desktop, tablet, and mobile
- **Smooth Animations**: Satisfying visual feedback for found words
- **Biblical Color Scheme**: Inspired by traditional biblical aesthetics

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/biblical-word-tetris.git
   cd biblical-word-tetris
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to play!

### Building for Production

```bash
npm run build
npm run preview
```

## 🎮 How to Play

### Controls
- **Arrow Keys**: Move falling letters (←, →, ↓)
- **Spacebar**: Drop letter instantly
- **R**: Restart game
- **P**: Pause/Resume game

### Mobile Controls
Touch buttons are provided for mobile devices with the same functionality.

### Objective
1. **Read the Bible Verse**: Each level shows a different Bible verse
2. **Form Words**: As letters fall, arrange them to spell words from the verse
3. **Score Points**: Longer words and harder verses give more points
4. **Progress**: Advance through difficulty levels with higher scores

### Game Modes
- **Switch between modes** anytime during gameplay
- **Tetris Mode**: Strategic play as found words disappear
- **Word Search Mode**: Relaxed play with persistent word highlighting

## 🏆 Difficulty System

Our intelligent algorithm rates each Bible verse based on:

1. **Word Count**: More words = higher difficulty
2. **Character Count**: Longer verses = more complex
3. **Letter Diversity**: More unique letters = harder
4. **Average Word Length**: Longer words = more challenging
5. **Uncommon Letters**: Q, X, Z, etc. increase difficulty
6. **Letter Repetition**: Less repetition = harder to form words
7. **Bible Book Difficulty**: Books like Job, Revelation are rated higher

### Difficulty Levels
- 🌱 **Beginner** (1-2): Simple, short verses
- 📖 **Easy** (3-4): Familiar verses with common words
- ⭐ **Intermediate** (5-6): Moderate length with some challenges
- 🔥 **Advanced** (7-8): Complex verses requiring skill
- 👑 **Expert** (9-10): Master level with intricate patterns
